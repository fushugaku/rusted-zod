# Dead Code Audit

Цель: rustc `dead_code` warnings не должны маскировать неподключенный перенос.

Правило:

- Если функция отражает поведение оригинала и нужна runtime-системам, сделать wiring.
- Если функция нужна только тесту и не является runtime API, оставить private без public facade или перенести тест ближе к владельцу.
- Если функция не подтверждена source trace и нигде не нужна, удалить.
- `#[allow(dead_code)]` не использовать для нового кода, кроме явного compatibility shim.
