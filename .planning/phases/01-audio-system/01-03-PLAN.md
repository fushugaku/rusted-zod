<task type="auto">
  <name>Task 1: Create ComputerVoice announcement queue system</name>
  <files>client/src/sound/ComputerVoice.ts</files>
  <action>
Create ComputerVoice.ts class with:

1. Announcement enum for all computer voice events:
   - VEHICLE_MANUFACTURED, ROBOT_MANUFACTURED, GUN_MANUFACTURED
   - STARTING_MANUFACTURE, MANUFACTURING_CANCELED
   - TERRITORY_LOST, FORT_UNDER_ATTACK
   - STARTING_REPAIR, VEHICLE_REPAIRED
   - RADAR_ACTIVATED
   - YOURE_LOSING (uses random variant 00-09)

2. Queue system:
   - Private queue: Announcement[]
   - Private currentlyPlaying: Phaser.Sound.BaseSound | null
   - Private soundSystem reference

3. announce(type: Announcement) method:
   - Add to queue
   - If not currently playing, start next

4. Private playNext() method:
   - If queue empty or currently playing, return
   - Pop from queue, map to sound key (e.g., VEHICLE_MANUFACTURED -> 'comp_vehicle_manufactured')
   - For YOURE_LOSING, pick random 00-09 variant
   - Play via soundSystem.play()
   - Set currentlyPlaying, listen for 'complete' event
   - On complete, clear currentlyPlaying, call playNext()

5. clearQueue() method for when game ends/resets

6. update(delta: number) method - can be used for timeout fallback if sound doesn't fire complete event

Voice files are ~1-3 seconds each, so queue prevents overlap.
  </action>
  <verify>File compiles, class exports correctly</verify>
  <done>ComputerVoice class with queue system, announce() method, all announcement types</done>
</task>
