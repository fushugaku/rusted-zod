1. **Animation state enum** - States the machine can be in:
   ```typescript
   export enum AnimationState {
     IDLE = 'idle',
     WALKING = 'walking',
     ATTACKING = 'attacking',
     DYING = 'dying',
     IDLE_ACTION = 'idle_action', // Beer, cigarette, etc.
   }
   ```

2. **AnimationStateMachine class**:
   ```typescript
   interface AnimationConfig {
     frameCount: number;
     frameDuration: number; // ms per frame
     loop: boolean;
     onComplete?: () => void;
   }

   export class AnimationStateMachine {
     private currentState: AnimationState;
     private currentFrame: number = 0;
     private frameTimer: number = 0;
     private animations: Map<string, AnimationConfig>;
     private currentAnimKey: string = '';
     private locked: boolean = false; // For death animations

     constructor() { ... }

     // Register an animation with its config
     registerAnimation(key: string, config: AnimationConfig): void;

     // Transition to a new state (respects locked state)
     transition(state: AnimationState, animKey: string): boolean;

     // Update frame based on delta time
     update(delta: number): void;

     // Get current frame for rendering
     getCurrentFrame(): number;

     // Lock state (for death - can't transition out)
     lock(): void;

     // Is current animation complete?
     isComplete(): boolean;
   }
   ```

3. **State transition rules**:
   - DYING state is locked - can't transition out
   - ATTACKING takes priority over WALKING
   - IDLE_ACTION can be interrupted by WALKING or ATTACKING
   - IDLE is the default fallback state

4. **Frame timing** - Use delta accumulation:
   ```typescript
   update(delta: number): void {
     if (this.locked && this.isComplete()) return;

     this.frameTimer += delta;
     const config = this.animations.get(this.currentAnimKey);
     if (!config) return;

     while (this.frameTimer >= config.frameDuration) {
       this.frameTimer -= config.frameDuration;
       this.currentFrame++;

       if (this.currentFrame >= config.frameCount) {
         if (config.loop) {
           this.currentFrame = 0;
         } else {
           this.currentFrame = config.frameCount - 1;
           config.onComplete?.();
         }
       }
     }
   }
   ```

5. Export from `index.ts`:
   ```typescript
   export * from './AnimationConstants';
   export * from './AnimationStateMachine';
   ```

Key: Follow timing values from `AnimationConstants.ts` exactly - WALK_FRAME_TIME is 100ms, IDLE_PROCESS_TIME is 300ms.
