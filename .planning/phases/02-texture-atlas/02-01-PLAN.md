<task type="auto">
  <name>Task 1: Install dependencies and create atlas packer script</name>
  <files>
    client/package.json
    client/scripts/pack-atlases.ts
    client/tsconfig.node.json
  </files>
  <action>
1. Install required dependencies:
   ```bash
   cd client && npm install --save-dev free-tex-packer-core glob @types/glob tsx
   ```

2. Create `client/tsconfig.node.json` for Node.js scripts:
   ```json
   {
     "compilerOptions": {
       "target": "ES2020",
       "module": "ESNext",
       "moduleResolution": "bundler",
       "esModuleInterop": true,
       "skipLibCheck": true,
       "strict": true,
       "outDir": "./dist-scripts"
     },
     "include": ["scripts/**/*.ts"]
   }
   ```

3. Create `client/scripts/pack-atlases.ts` that:
   - Uses free-tex-packer-core with Phaser3 exporter
   - Packs by category: robots, vehicles, cannons, buildings, effects, cursors, map_items
   - Separates by team for team-colored sprites (robots_red, robots_blue, etc.)
   - Generates frame names matching EXISTING sprite key patterns in SpriteLoader.ts:
     * Robot stand: `robot_stand_{team}_r{rot}` (from filename `stand_{team}_r{rot}.png`)
     * Robot walk: `robot_walk_{team}_r{rot}_n{frame}` (from filename `walk_{team}_r{rot}_n{frame}.png`)
     * Robot fire: `robot_{type}_fire_{team}_r{rot}_n{frame}` (from path `robots/{type}/fire_{team}...`)
     * Vehicle base: `vehicle_{type}_base_{team}_r{rot}_n{frame}` (from path `vehicles/{type}/base_{team}...`)
     * Vehicle top: `vehicle_{type}_top_r{rot}` or `vehicle_{type}_top_{team}_r{rot}` (varies)
     * Cannon: `cannon_{type}_{state}_{team}_r{rot}_n{frame}` patterns
     * Effects/buildings: preserve existing patterns from SpriteLoader
   - Uses options: width 2048, height 2048, powerOfTwo true, padding 1, allowRotation false
   - Outputs to `client/assets/atlases/`

   Key: The frame name generation MUST match the sprite key patterns in SpriteLoader.ts exactly.
   Parse the file path to construct the same key that SpriteLoader.ts generates.

4. Add npm scripts to package.json:
   ```json
   "scripts": {
     "pack-atlases": "tsx scripts/pack-atlases.ts",
     "dev": "npm run pack-atlases && vite",
     "build": "npm run pack-atlases && tsc && vite build"
   }
   ```

CRITICAL: Frame names must match EXACTLY what Robot.ts, Vehicle.ts, Cannon.ts expect via getSpriteKey() methods.
Study the sprite key patterns in SpriteLoader.ts loadRobotSprites(), loadVehicleSprites(), loadCannonSprites() etc.
  </action>
  <verify>
    - `npm run pack-atlases` completes without errors
    - Atlas files exist in `client/assets/atlases/`
    - `robots_red.json` contains frame names like "robot_stand_red_r000", "robot_walk_red_r045_n00"
  </verify>
  <done>
    - pack-atlases.ts script exists and runs
    - At least 16 atlas files generated (4 teams x 4 categories)
    - JSON frame names match existing sprite key patterns
  </done>
</task>
