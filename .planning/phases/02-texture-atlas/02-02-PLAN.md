1. **Modify SpriteLoader.ts** to load atlases instead of individual images:

   Replace the individual `this.scene.load.image()` calls with `this.scene.load.atlas()` calls.

   Example transformation in loadRobotSprites():
   ```typescript
   // BEFORE (many individual loads):
   // for (const team of teams) {
   //   for (let rot = 0; rot < 8; rot++) {
   //     this.scene.load.image(key, path);
   //   }
   // }

   // AFTER (single atlas per team):
   public loadRobotAtlases(): void {
     const teams = ['red', 'blue', 'green', 'yellow'];
     for (const team of teams) {
       this.scene.load.atlas(
         `robots_${team}`,
         `assets/atlases/robots_${team}.png`,
         `assets/atlases/robots_${team}.json`
       );
     }
   }
   ```

2. **Add atlas key mapping** - Create method to determine which atlas contains a sprite:
   ```typescript
   public getAtlasForSprite(spriteKey: string): string | undefined {
     // Parse sprite key to determine atlas

     // "vehicle_light_base_blue_r000_n00" -> "vehicles_blue"
     // "cannon_gatling_fire_green_r000_n00" -> "cannons_green"
     // "side_explosion_n00" -> "effects"
   }
   ```

3. **Update all load methods**:

   - `loadCannonSprites()` -> `loadCannonAtlases()` (loads 4 atlases + neutral)
   - `loadBuildingSprites()` -> `loadBuildingAtlases()` (loads building atlases)
   - `loadEffectSprites()` -> `loadEffectAtlases()` (loads effects atlas)
   - `loadMapItemSprites()` -> keep as-is if not in atlas, or load map_items atlas
   - `loadFlagSprites()` -> keep as-is or include in appropriate atlas
